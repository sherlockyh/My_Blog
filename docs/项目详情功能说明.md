# 项目详情与后台配置

项目卡片统一进入 `/projects/:id`，详情页展示标题、简介、标签、封面和 Markdown 正文；配置了有效访问地址时显示“访问项目”，点击后在新标签页打开。首页精选项目与项目列表使用相同入口。

## 后台编辑

后台“项目管理”的新增、编辑、查看继续使用弹窗。中英文分别维护标题、卡片简介和正文；右侧配置封面、标签、项目访问地址、精选及排序。

- 正文使用 Markdown，支持预览；每种语言最多 50000 字符。
- 查看模式渲染正文，只读展示。
- 英文内容为空时，前台回退到中文内容。
- 正文和访问地址都允许留空，存量项目不需要补齐正文才能展示。
- 访问地址必须包含 `http://` 或 `https://`；存量无效地址不会显示访问按钮。
- 详情加载失败时禁用保存，重试加载成功后再编辑。
- 关闭有修改的弹窗时确认是否放弃；保存期间避免重复提交。

## 接口联调

本地后端默认端口 `7001`，全局前缀 `/api`；前端通过同源 `/api` 代理访问。实际端口可由后端 `PORT` 覆盖。

| 方法 | 完整本地 URL                                                  | 用途                   |
| ---- | ------------------------------------------------------------- | ---------------------- |
| GET  | `http://localhost:7001/api/projects`                          | 公开列表，不含正文     |
| GET  | `http://localhost:7001/api/projects/1`                        | 公开完整详情           |
| GET  | `http://localhost:7001/api/admin/projects?page=1&pageSize=10` | 后台分页列表，不含正文 |
| GET  | `http://localhost:7001/api/admin/projects/1`                  | 后台完整详情           |
| POST | `http://localhost:7001/api/admin/projects`                    | 新增项目               |
| PUT  | `http://localhost:7001/api/admin/projects/1`                  | 修改项目               |

后台接口携带 `Authorization: Bearer <token>`。成功响应沿用 `{ code: 0, data, message }`，前端请求层已解包为 `data`；后台列表的 `data` 仍是 `{ items, total, page, pageSize }`。

新增、修改请求体示例：

```json
{
  "titleZh": "会议室预约系统",
  "titleEn": "Meeting Room Booking",
  "descZh": "支持会议室查询和在线预约。",
  "descEn": "Find and book meeting rooms.",
  "contentZh": "## 项目背景\n介绍项目用途。\n\n## 核心功能\n- 会议室查询\n- 在线预约",
  "contentEn": "## Overview\nA meeting room booking application.",
  "cover": "/uploads/example.png",
  "tags": ["React", "TypeScript"],
  "link": "https://example.com",
  "featured": true,
  "sort": 0
}
```

详情返回现有项目字段及 `contentZh`、`contentEn`。使用 `ProjectDetailDTO` 接收详情，列表继续使用 `ProjectDTO`。未找到项目返回 404；错误地址、正文超长或类型错误返回 400。

项目保存接口单独支持 512KB JSON 请求，其他接口沿用原有请求大小限制。Markdown 图片使用链接引用，不在 JSON 正文中嵌入图片文件。

## 数据迁移与发布

迁移 `20261020000000_project_content` 为 `Project` 新增两个非空文本列：`contentZh`、`contentEn`，默认值为空字符串，不修改既有简介、链接等数据。

部署新后端前执行：

```sh
pnpm db:migrate:deploy
```

当前 Docker 启动脚本会执行 `prisma migrate deploy`。需要同时更新前后端构建产物，避免旧后端无法保存正文或无法提供详情接口。
