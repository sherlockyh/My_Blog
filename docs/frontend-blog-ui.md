# 前台博客 UI 与模块说明

## 页面边界

- 公开博客：`/`、`/articles`、`/articles/:slug`、`/archives`、`/categories`、`/tags`、`/about` 等路由只负责展示、阅读和筛选。
- 后台管理：`/admin` 路由负责文章、项目、资源、留言、首页配置和个人信息编辑。
- 管理入口保留在 Footer，避免公开导航混入编辑功能。

## 视觉方向

当前 UI 按设计图统一为科技蓝主题：

- 亮色模式：浅蓝背景、白色玻璃卡片、蓝色高亮、代码立方体 Hero 视觉。
- 深色模式：深蓝背景、蓝色发光边线、数字星球 Hero 视觉。
- 卡片圆角保持 8px，页面布局保持紧凑，优先服务阅读和信息扫描。

## 模块组成

- 首页：Hero、6 个技能入口、推荐文章三卡、最新文章列表、关于我、热门标签。
- 文章列表：标题说明、搜索、标签筛选、分页、文章卡片、右侧公共侧栏。
- 文章详情：返回列表、头图、标题摘要、发布时间、浏览量、标签、Markdown 正文、右侧公共侧栏。
- 归档/分类/标签：从公开文章派生，所有入口都跳转到文章详情或带筛选条件的文章列表。

## 数据兜底

公开博客页优先消费后端公开接口。开发环境中如果后端或数据库不可用，首页、文章列表、文章详情、归档、分类和标签页会使用本地演示内容兜底，保证 UI 对齐和阅读链路可验证。后台管理页不使用这份兜底数据，避免误把演示内容当成真实编辑数据。

## 响应式策略

- 桌面端：主体内容 + 右侧栏两列布局。
- 平板端：主体与侧栏上下排列，侧栏变为两列。
- 手机端：所有模块单列展示，封面比例变高，标题和正文内边距收敛，避免文字溢出和模块重叠。

## 扩展建议

- 如果文章量超过几百篇，文章列表建议从页码分页升级到 `publishedAt + id` 游标分页。
- 如果需要 SEO，前台博客可以迁移到 SSG/SSR；后台仍保持 SPA 管理端。
- 如果图片资源增长，封面图应增加缩略图、压缩和 CDN。
